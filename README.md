# DevOps Pirate Voyage

**Путь DevOps-пирата** — интерактивное образовательное веб-приложение для самостоятельного изучения DevOps.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Возможности

- 🗺️ Карта путешествия с 7 островами: Linux → Сети → Ansible → Terraform → Docker → Kubernetes → GitLab CI/CD
- 📚 Теория, мини-практика и контрольные квизы (140+ вопросов)
- ⛈️ Шторм незнания и Storm Challenge
- 📋 Журнал ошибок с финальным обзором
- 💎 Остров оффера — загрузка реального PDF оффера
- 🏆 Геймификация: XP, mastery, достижения, streak

## Стек

- React + TypeScript + Vite
- Tailwind CSS
- Framer Motion
- Zustand (localStorage)
- IndexedDB (PDF)

## Данные

Весь прогресс хранится локально в браузере. PDF оффера не отправляется на сервер.
